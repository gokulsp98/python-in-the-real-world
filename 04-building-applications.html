Every app starts with someone writing the code behind it.

Someone built that "Submit Complaint" button. This time, that someone is you.

Every form you've filled, every button you've clicked — a developer sat down and wrote the code that makes it actually do something. Today, that's what we're building: the system behind the ticket.

So what are we actually building?

A web app is just three things talking to each other.

You fill out a form — that's the frontend. It sends a request to a server — that's the backend. The server decides what to do and saves it — that's the database. Python's home turf is the middle one.

Backend (Python)

What you actually see

The frontend is the form itself.

The complaint box, the submit button, the little spinner while it loads — HTML, CSS, and JavaScript, running right in your browser. It's not where Python lives, but it's where every ticket begins.

The part nobody sees

The backend is where Python actually runs.

The moment you hit submit, the frontend sends that complaint to a server. Python code there checks it, saves it, and sends back a simple reply. No magic — just receive, check, save, reply.

Python gives you more than one way to build this

Three popular choices: Flask, Django, FastAPI.

We're not going deep on all three — just so the names aren't strangers later.

Flask — minimal, you build it piece by piece
Django — batteries included, even a free admin dashboard
FastAPI — modern and fast — the one we're using today

Let's actually look at the one we picked

FastAPI — what it does with that request.

You describe the shape of a ticket once. FastAPI checks every incoming request against that shape automatically, saves the valid ones, and hands you interactive docs you never had to write.

Checks data automatically Free interactive docs Handles many requests at once

And that save goes exactly… here

Into an OLTP database.

Every ticket that gets created or updated lands as one row in a database built for fast, cheap, one-at-a-time writes. We're about to spend an entire session on exactly this.
